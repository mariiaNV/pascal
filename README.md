# Pascal Tire Studio — сайт

Статичний сайт без залежностей: відкрийте `index.html` (або `python3 -m http.server`).

## Що заповнити власнику (все позначено в коді)
- `js/config.js` — Telegram/Viber (лише підтверджені), URL форми (`formEndpoint`), GTM/GA4 ID.
- `index.html` — домен замість `pascal-tire.example` (canonical, og:url, JSON-LD), `sitemap.xml`, `robots.txt`.
- Послуги: `data-confirmed="false"` → `true` після підтвердження.
- Блок «Чому Pascal»: `data-placeholder="true"` — замінити на підтверджені факти.
- Відгуки: замінити демо-картки реальними публічними відгуками.
- Фото: усі зображення — кадри з одного реального фото (`assets/photo/original.png`), нарізані `tools/crops.mjs`. Для кращої якості замініть на окремі фото високої роздільності.
- Графік роботи: у Google указано лише закриття о 23:00 — додати повний після підтвердження.
- `tools/crops.mjs` — нарізка кадрів і OG-картинка.
- На вивісці є значок «24 години», а в Google вказано закриття о 23:00 — уточніть реальний графік.
